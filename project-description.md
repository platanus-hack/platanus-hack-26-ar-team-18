# casita-fast

Agente inmobiliario de IA que busca, filtra y contacta vendedores para encontrar propiedades más rápido.

## El problema

Buscar una propiedad hoy no es elegir entre buenas opciones: es perder horas filtrando publicaciones repetidas, precios inflados, datos incompletos y vendedores que no contestan.

El usuario termina haciendo trabajo manual: comparar propiedades, detectar oportunidades reales, escribirle a cada vendedor y esperar respuestas. El proceso es lento, desordenado y frustrante.

## La solución

casita-fast actúa como un agente inmobiliario personal asistido por IA.

El sistema analiza propiedades disponibles, prioriza las mejores oportunidades y decide qué vendedores contactar. Luego puede iniciar conversaciones, hacer preguntas relevantes y avanzar el proceso hasta que el usuario tenga opciones concretas para coordinar una visita o primera reunión.

## Cómo funciona

1. **Búsqueda y análisis de propiedades**  
   El agente revisa publicaciones inmobiliarias, identifica datos relevantes y compara opciones según precio, ubicación, características y señales de calidad.

2. **Filtrado inteligente**  
   Detecta publicaciones repetidas, precios inflados o propiedades que no cumplen con lo que el usuario está buscando.

3. **Contacto con vendedores**  
   El agente contacta a los vendedores, hace preguntas clave y recopila información que normalmente el usuario tendría que pedir manualmente.

4. **Resumen para el usuario**  
   El usuario recibe solo las oportunidades más relevantes, con contexto suficiente para decidir si avanzar o no.

## Valor principal

casita-fast reduce el tiempo perdido en búsquedas inmobiliarias y acerca al usuario a propiedades reales, disponibles y mejor calificadas.

Menos publicaciones irrelevantes.  
Menos mensajes manuales.  
Más velocidad para encontrar una propiedad que tenga sentido.

## Stack técnico

Frontend: Next.js  
Backend: NestJS  
Automatización y contacto: WhatsApp / Kapso  
IA: agentes para análisis, priorización y conversación  
Deploy: Vercel
